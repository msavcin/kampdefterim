📍 Konum İzinleri Raporu

Kamp Defterim Uygulamasında Konum İzinlerinin Kapsamlı Analizi

Rapor Tarihi: 5 Şubat 2026

Uygulama Versiyonu: 1.3.3

Platform: Android (Expo-React Native)

🎯 Genel Bakış

Kamp Defterim uygulaması, kullanıcılara en iyi kamp deneyimini sunabilmek için konum tabanlı özellikler sunar. Bu rapor, uygulamada kullanılan tüm konum izinlerini, kullanım amaçlarını ve teknik detaylarını içerir.

📋 İzin Türleri

Uygulamada kullanılan konum izinleri üç ana kategoriye ayrılır:

İzin Türü Android İzni Kullanım Amacı Gereklilik
Foreground (Ön Plan) ACCESS_FINE_LOCATION
ACCESS_COARSE_LOCATION		 Uygulama açıkken konum bilgisi alma, haritada kullanıcı konumunu gösterme Tüm kullanıcılar için temel
Background (Arka Plan) ACCESS_BACKGROUND_LOCATION
FOREGROUND_SERVICE_LOCATION		 Offline mod için arka planda harita tile'larını otomatik indirme Sadece Premium kullanıcılar
Foreground Service FOREGROUND_SERVICE Arka plan konum takibi sırasında sistem bildirimleri Premium özellikleri için

🔧 Teknik İmplementasyon

1. Android Manifest İzinleri

Dosya: app.json

Uygulamanın Android manifestinde tanımlanan izinler:

"permissions": [ "android.permission.ACCESS_FINE_LOCATION", "android.permission.ACCESS_COARSE_LOCATION", "android.permission.ACCESS_BACKGROUND_LOCATION", "android.permission.FOREGROUND_SERVICE", "android.permission.FOREGROUND_SERVICE_LOCATION" ]

2. Expo Location Konfigürasyonu

Dosya: app.json (plugins bölümü)

"expo-location": { "locationAlwaysAndWhenInUsePermission": "Offline harita senkronizasyonu için konum izni gereklidir.", "locationAlwaysPermission": "Arka planda offline harita güncellemeleri için konum izni gereklidir.", "locationWhenInUsePermission": "Harita ve kamp alanlarını görmek için konum izni gereklidir.", "isAndroidBackgroundLocationEnabled": true, "isAndroidForegroundServiceEnabled": true }

3. Konum İzni Kontrol Fonksiyonları

3.1 Premium Kullanıcı İzin Kontrolü

Dosya: lib/checkLocationPermissionsForPremium.ts

Amaç: Premium kullanıcıların hem ön plan hem de arka plan izinlerinin olup olmadığını kontrol eder.

export async function checkLocationPermissionsForPremium(user) { // Premium kullanıcıda hem foreground hem background izin granted olmalı if (!user?.offline_enabled) return true; const fg = await Location.getForegroundPermissionsAsync(); if (fg.status !== 'granted') return false; const bg = await Location.getBackgroundPermissionsAsync(); return bg.status === 'granted'; }

Kullanım Senaryosu:

  • Offline mod aktif olan kullanıcılar için çalışır
  • Foreground izni yoksa false döner
  • Background izni yoksa false döner
  • Her iki izin de varsa true döner

3.2 Konum İzni Modal Componenti

Dosya: components/LocationPermissionModal.tsx

Amaç: Kullanıcıya konum izni gereksinimlerini açıklayan ve izin isteyen modal pencere.

Özellikler:

  • ✅ Premium ve normal kullanıcılar için farklı mesajlar
  • ✅ Foreground izin isteği
  • ✅ Premium kullanıcılar için background izin isteği
  • ✅ "Bir daha hatırlatma" seçeneği
  • ✅ Sistem ayarlarına yönlendirme (izin reddedildiyse)
  • ✅ AppState listener ile uygulama ön plana geldiğinde izin kontrolü

Kullanım Yerleri:

  • Ana ekran (index.tsx) - Uygulama ilk açıldığında
  • Profil sayfası - Manuel izin talebi için

3.3 Konum Takibi (useCampingAreas Hook)

Dosya: hooks/useCampingAreas.ts

Amaç: Kullanıcının konumunu takip eder ve kamp alanlarını getirir.

İşlevler:

  • getCurrentLocation(): Mevcut konumu bir kez alır
  • watchPositionAsync(): Konum değişikliklerini sürekli izler
  • Varsayılan Konum: İzin yoksa Ankara (39.9251, 32.8375) kullanılır
const { status } = await Location.getForegroundPermissionsAsync(); if (status === 'granted') { locationSubscription = await Location.watchPositionAsync( { accuracy: Location.Accuracy.Balanced, distanceInterval: 100, // 100m hareket timeInterval: 30000, // 30 saniye }, (newLocation) => { setLocation(newLocation); } ); }

📱 Kullanıcı Deneyimi Akışları

Normal Kullanıcı Akışı

  1. Uygulama açılır
  2. Foreground konum izni kontrol edilir
  3. İzin yoksa LocationPermissionModal gösterilir
  4. Kullanıcı "Konum İzni Ver" butonuna basar
  5. requestForegroundPermissionsAsync() çağrılır
  6. İzin verilirse:
    • Kullanıcının konumu alınır
    • Harita konuma odaklanır
    • Yakındaki kamp alanları gösterilir
  7. İzin verilmezse:
    • Varsayılan konum (Ankara) kullanılır
    • Kullanıcı manuel olarak haritada gezinebilir

Premium Kullanıcı Akışı (Offline Mode)

  1. Uygulama açılır
  2. Foreground konum izni kontrol edilir
  3. İzin yoksa modal gösterilir (Premium mesajı ile)
  4. Kullanıcı "Konum İzni Ver" butonuna basar
  5. requestForegroundPermissionsAsync() çağrılır
  6. Foreground izin verildikten sonra:
  7. getBackgroundPermissionsAsync() ile mevcut durum kontrol edilir
  8. Background izni yoksa requestBackgroundPermissionsAsync() çağrılır
  9. Sistem, kullanıcıya "Her zaman izin ver" seçeneğini sunar
  10. Kullanıcı "Her zaman izin ver" seçerse:
    • Offline mode tamamen aktif olur
    • Arka planda harita tile'ları otomatik indirilir
    • Konum değişikliklerinde cache güncellenir
  11. Kullanıcı "Sadece uygulama kullanımda" seçerse:
    • Uyarı mesajı gösterilir
    • Profil sayfasından izin ayarlanabilir

🔒 Gizlilik ve Güvenlik

⚠️ Konum Verisi Kullanımı

  • Veri Saklama: Konum verileri sadece cihazda yerel olarak saklanır
  • Sunucuya Gönderim: Kullanıcı konumu sunucuya gönderilmez
  • Üçüncü Taraf Paylaşımı: Konum bilgileri üçüncü taraflarla paylaşılmaz
  • Kullanım Amacı: Sadece harita görüntüleme ve kamp alanı arama için kullanılır
  • Offline Mode: Premium kullanıcılar için arka planda sadece harita tile'ları indirilir, konum kaydedilmez

📊 İstatistikler ve Kullanım

Konum Takip Parametreleri

  • Accuracy: Location.Accuracy.Balanced
  • Distance Interval: 100 metre (100m hareket edince güncelleme)
  • Time Interval: 30 saniye (minimum güncelleme süresi)
  • Varsayılan Radius: 20 km (kamp alanı arama çapı)
  • Offline Cache Radius: 20 km (konum değişikliğinde otomatik cache)
  • Konum Değişiklik Threshold: 1 km (cache tetikleme mesafesi)

🛠️ Geliştirici Notları

İzin İstek Sırası

1. getForegroundPermissionsAsync() - Mevcut durumu kontrol 2. requestForegroundPermissionsAsync() - Foreground izin iste 3. getBackgroundPermissionsAsync() - Background durum kontrol (sadece premium) 4. requestBackgroundPermissionsAsync() - Background izin iste (sadece premium)

Hata Yönetimi

  • İzin Reddedilirse: Varsayılan konum (Ankara) kullanılır
  • Sistem Ayarları: Linking.openSettings() ile kullanıcı sistem ayarlarına yönlendirilir
  • İzin Tekrar İstenemiyorsa: canAskAgain === false durumunda direkt ayarlara gönderilir

State Yönetimi

  • SecureStore: doNotShowLocationPermissionModal tercih saklanır
  • EventBus: locationPermissionGranted eventi ile komponentler arası iletişim
  • AppState Listener: Uygulama ön plana geldiğinde izin durumu kontrol edilir
