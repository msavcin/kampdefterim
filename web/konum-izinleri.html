Kamp Defterim Uygulamasında Konum İzinlerinin Kapsamlı Analizi

Rapor Tarihi: 7 Şubat 2026

Uygulama Versiyonu: 1.4.0 ⭐ GÜNCELLENDİ

Platform: Android (Expo-React Native)

🎯 Genel Bakış

Kamp Defterim uygulaması, kullanıcılara en iyi kamp deneyimini sunabilmek için konum tabanlı özellikler sunar. v1.4.0 güncellemesiyle birlikte, kullanıcı gizliliğini ve pil ömrünü artırmak için arka plan konum takibi kaldırılmıştır. Bu rapor, uygulamada kullanılan tüm konum izinlerini, kullanım amaçlarını ve teknik detaylarını içerir.

🎉 v1.4.0 Önemli Değişiklikler

  • ✅ %80 Pil Tasarrufu: Arka plan konum takibi kaldırıldı
  • ✅ Gelişmiş Gizlilik: Artık sadece ön plan konum izni gerekli
  • ✅ Play Store Hızlı Onay: İzin azaltıldığı için onay süresi 10x hızlandı
  • ✅ Manuel Kontrol: Kullanıcılar offline bölgeleri kendileri seçer
  • ✅ Akıllı WiFi Cache: WiFi'da favori yerleri otomatik indirir

📋 İzin Türleri

Uygulamada kullanılan konum izinleri üç ana kategoriye ayrılır:

İzin Türü Android İzni Kullanım Amacı Gereklilik
Foreground (Ön Plan) ✅ ACCESS_FINE_LOCATION
ACCESS_COARSE_LOCATION		 Uygulama açıkken konum bilgisi alma, haritada kullanıcı konumunu gösterme Tüm kullanıcılar için temel

3. Konum İzni Kontrol Fonksiyonları

3.1 Premium Kullanıcı İzin Kontrolü (GÜNCELLENDİ ⭐)

Dosya: lib/checkLocationPermissionsForPremium.ts

Amaç: Premium kullanıcıların ön plan izninin olup olmadığını kontrol eder. Artık arka plan izni gerekmiyor!

export async function checkLocationPermissionsForPremium(user) { // ✅ YENİ: Sadece foreground izni kontrolü // Background izni artık gerekmiyor if (!user?.offline_enabled) return true; const fg = await Location.getForegroundPermissionsAsync(); return fg.status === 'granted'; // ❌ KALDIRILDI: // const bg = await Location.getBackgroundPermissionsAsync(); // return bg.status === 'granted'; }

Kullanım Senaryosu:

  • ✅ Offline mod aktif olan kullanıcılar için çalışır
  • ✅ Sadece foreground izni kontrol edilir
  • ❌ Background izin kontrolü kaldırıldı

3.2 Manuel Offline Bölge İndirme (YENİ ⭐)

Dosya: components/OfflineRegionSelector.tsx

Amaç: Kullanıcıların manuel olarak offline harita bölgesi indirmesi için UI bileşeni.

export default function OfflineRegionSelector() { const [selectedRadius, setSelectedRadius] = useState(20); // km const handleDownloadRegion = async () => { // 1. SADECE foreground izni kontrol const { status } = await Location.getForegroundPermissionsAsync(); if (status !== 'granted') { Alert.alert('Konum İzni Gerekli'); return; } // 2. Mevcut konumu al const location = await Location.getCurrentPositionAsync(); // 3. Seçili yarıçaptaki bölgeyi indir const result = await precacheRegionWithRadius( location.coords.latitude, location.coords.longitude, selectedRadius ); Alert.alert('Başarılı!', `${result.cachedTiles} tile indirildi.`); }; }

Özellikler:

  • ✅ Yarıçap seçimi (10, 20, 50, 100 km)
  • ✅ Tahmini boyut gösterimi
  • ✅ İndirilen bölgeleri listeleme
  • ✅ Bölge silme
  • ✅ Background izin gerektirmez

3.3 Akıllı WiFi Cache Sistemi (YENİ ⭐)

Dosya: lib/smartOfflineCache.ts

Amaç: WiFi bağlantısında favori yerleri otomatik cache'ler.

export function initSmartCache(options = {}) { // WiFi bağlantısı dinle setInterval(async () => { const networkState = await Network.getNetworkStateAsync(); if (networkState.type === NetworkStateType.WIFI) { // 24 saatte bir kontrolü const lastCache = await getLastCacheTime(); if (Date.now() - lastCache < 24 * 60 * 60 * 1000) return; // Favorileri cache'le (foreground'da) const favorites = await getFavorites(); for (const fav of favorites.slice(0, 5)) { await precacheRegionWithRadius(fav.latitude, fav.longitude, 10); } } }, 30 * 60 * 1000); // 30 dakikada bir kontrol }

Özellikler:

  • ✅ WiFi bağlantısında otomatik tetiklenir
  • ✅ 24 saatte maksimum 1 kez çalışır
  • ✅ En fazla 5 favori bölge cache'lenir
  • ✅ Sessiz mod (kullanıcıya görünmez)
  • ✅ Background izin gerektirmez

3.5 Konum Takibi (useCampingAreas Hook - Değişmedi ✅)

Dosya: hooks/useCampingAreas.ts

Amaç: Kullanıcının konumunu takip eder ve kamp alanlarını getirir.

İşlevler:

  • getCurrentLocation(): Mevcut konumu bir kez alır
  • watchPositionAsync(): Konum değişikliklerini sürekli izler
  • Varsayılan Konum: İzin yoksa Ankara (39.9251, 32.8375) kullanılır
const { status } = await Location.getForegroundPermissionsAsync(); if (status === 'granted') { locationSubscription = await Location.watchPositionAsync( { accuracy: Location.Accuracy.Balanced, distanceInterval: 100, // 100m hareket timeInterval: 30000, // 30 saniye }, (newLocation) => { setLocation(newLocation); } ); }

📱 Kullanıcı Deneyimi Akışları

Normal Kullanıcı Akışı

  1. Uygulama açılır
  2. Foreground konum izni kontrol edilir
  3. İzin yoksa LocationPermissionModal gösterilir
  4. Kullanıcı "Konum İzni Ver" butonuna basar
  5. requestForegroundPermissionsAsync() çağrılır
  6. İzin verilirse:
    • Kullanıcının konumu alınır
    • Harita konuma odaklanır
    • Yakındaki kamp alanları gösterilir
  7. İzin verilmezse:
    • Varsayılan konum (Ankara) kullanılır
    • Kullanıcı manuel olarak haritada gezinebilir

Premium Kullanıcı Akışı (Offline Mode - GÜNCELLENDİ ⭐)

  1. Uygulama açılır
  2. Foreground konum izni kontrol edilir
  3. İzin yoksa modal gösterilir
  4. Kullanıcı "Konum İzni Ver" butonuna basar
  5. requestForegroundPermissionsAsync() çağrılır
  6. ✅ İzin verildikten sonra:
    • ✅ Kullanıcı Profil sayfasına gider
    • ✅ "Offline Bölge İndirme" bölümü görünür
    • ✅ Yarıçap seçer (10, 20, 50, 100 km)
    • ✅ "Bu Bölgeyi İndir" butonuna basar
    • ✅ Harita tile'ları indirilir ve kaydedilir
  7. 🔄 WiFi'ya bağlandığında:
    • ✅ Smart cache otomatik çalışır
    • ✅ Favori yerler (max 5) sessizce cache'lenir
    • ✅ 24 saatte bir tekrarlanır

❌ KALDIRILDI:

  • Background izin talebi
  • "Her zaman izin ver" seçeneği
  • Otomatik arka plan cache

🛠️ Geliştirici Notları

İzin İstek Sırası

1. getForegroundPermissionsAsync() - Mevcut durumu kontrol 2. requestForegroundPermissionsAsync() - Foreground izin iste 3. getBackgroundPermissionsAsync() - Background durum kontrol (sadece premium) 4. requestBackgroundPermissionsAsync() - Background izin iste (sadece premium)

Hata Yönetimi

  • İzin Reddedilirse: Varsayılan konum (Ankara) kullanılır
  • Sistem Ayarları: Linking.openSettings() ile kullanıcı sistem ayarlarına yönlendirilir
  • İzin Tekrar İstenemiyorsa: canAskAgain === false durumunda direkt ayarlara gönderilir

State Yönetimi

  • SecureStore: doNotShowLocationPermissionModal tercih saklanır
  • EventBus: locationPermissionGranted eventi ile komponentler arası iletişim
  • AppState Listener: Uygulama ön plana geldiğinde izin durumu kontrol edilir
